## 님만 할 수 있는 것

### 1. 릴리스 서명 키 만들기 — 가장 먼저, 가장 중요

**이 키를 잃으면 그 앱은 영영 업데이트할 수 없습니다.** 같은 `applicationId`로 새 앱을
올릴 수도 없습니다. 백업을 두 군데 이상 두세요.

```
keytool -genkeypair -v \
  -keystore person-dic-release.jks \
  -alias persondic \
  -keyalg RSA -keysize 4096 -validity 10000
```

- **저장소에 넣지 마세요.** `.gitignore`에 `*.jks`가 들어 있는지 확인하고, 파일은
  저장소 밖(비밀번호 관리자, 암호화된 외장 디스크)에 두세요.
- Play App Signing을 쓰면 이 키는 *업로드 키*가 됩니다. 배포 키는 구글이 보관하므로
  업로드 키를 잃어도 복구 요청이 가능합니다 — **그래도 잃지 마세요.**
- CI에서 서명하려면 키를 base64로 GitHub Secrets에 넣고 `signingConfigs`에
  릴리스 설정을 추가해야 합니다. 원하시면 그 부분은 제가 붙일 수 있습니다.

### 2. Play Console 개인 개발자 계정

- 등록비 $25 (1회)
- **신규 개인 계정은 비공개 테스트를 통과해야 프로덕션에 올릴 수 있습니다** —
  테스터 12명이 **연속 14일** 옵트인 상태여야 합니다. 지인 12명을 미리 확보해 두세요.
- 신원 확인에 며칠 걸립니다.

### 3. 처리방침 호스팅

`docs/privacy-policy.md`의 연락처를 채우고, 저장소 Settings → Pages에서 `docs/`를
켜면 URL이 나옵니다. Play는 **접근 가능한 URL**을 요구합니다.

### 4. 릴리스 APK를 실제로 돌려보기

**R8이 빌드된다는 것과 동작한다는 것은 다릅니다.** 릴리스 빌드를 설치해서:

- [ ] 앱이 켜지고 인물 목록이 나오는가
- [ ] **백업을 내보내고 다시 불러오는가** — R8이 직렬화기를 지웠다면 여기서 터집니다
- [ ] 사진이 백업에 들어갔다 나오는가
- [ ] 기존 데이터가 있는 기기에서 마이그레이션이 도는가

CI는 이 넷을 못 합니다.

## 제가 할 수 있는 것 — 말씀만 하시면

- [ ] CI에 릴리스 서명 붙이기 (GitHub Secrets에서 키 읽기)
- [ ] `versionName`을 수동 관리로 바꾸기 — 스토어 버전은 `0.1.<CI 실행번호>`처럼
      빌드마다 튀면 안 됩니다. `versionName = "1.0.0"` 같은 고정값 + `versionCode`만 자동 증가
- [ ] 스토어 등록 문구 초안 (제목·짧은 설명·전체 설명)
- [ ] 스크린샷 찍는 순서 정리 (Play는 최소 2장, 권장 4~8장)
- [ ] 데이터 보안 양식 답변 정리 — `docs/privacy-policy.md` 하단에 이미 있음
